# A CRM Application for TheChaiShop&Co

A Salesforce-based CRM project for customer, employer and enterprise management, automated billing, birthday email automation, reports and dashboards.

## Documentation
- [Complete Project Documentation (PDF)](docs/A_CRM_Application_TheChaiShopCo.pdf)
- [Editable Documentation (DOCX)](docs/A_CRM_Application_TheChaiShopCo.docx)

## Core Features
- Customer, Employer and Enterprise custom objects
- Online Order and Walk-In Order record types
- Page layouts and global picklists
- Validation rules
- Automated Order Quantity and Total Bill formulas
- Birthday Email Template, Email Alert and scheduled Flow
- Customer and Enterprise sales reports
- Customer Vs Enterprise Sales dashboard
